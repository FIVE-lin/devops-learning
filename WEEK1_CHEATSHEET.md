РАЗДЕЛ 1. НАВИГАЦИЯ И ФАЙЛОВАЯ СИСТЕМА
Структура файловой системы Linux:

    / — корневая директория
    /home/ — домашние папки пользователей
    /etc/ — конфигурационные файлы
    /var/ — переменные данные (логи, кэш)
    /tmp/ — временные файлы
    /usr/ — программы пользователей
    /bin/ — системные программы

Основные команды:
pwd — показать текущую папку
Пример: pwd
ls — показать содержимое папки
Пример: ls -la (показать скрытые файлы и права)
Пример: ls -R (показать все вложенные папки)
cd — перейти в папку
Пример: cd /etc
Пример: cd .. (на уровень выше)
Пример: cd ~ (в домашнюю папку)
Пример: cd - (вернуться в предыдущую папку)
mkdir — создать папку
Пример: mkdir test
Пример: mkdir -p a/b/c (создать вложенные папки)
touch — создать пустой файл
Пример: touch file.txt
cp — копировать файл или папку
Пример: cp file.txt backup.txt
Пример: cp -r folder/ backup_folder/ (копировать папку)
mv — переместить или переименовать
Пример: mv file.txt folder/ (переместить)
Пример: mv old.txt new.txt (переименовать)
rm — удалить файл или папку
Пример: rm file.txt
Пример: rm -r folder/ (удалить папку с содержимым)
Пример: rm -f file.txt (удалить без подтверждения)
Абсолютные и относительные пути:

    Абсолютный путь начинается с / или ~. Пример: /home/student/devops-learning/scripts/test.sh
    Относительный путь не начинается с /. Зависит от текущей папки. Пример: scripts/test.sh

Специальные обозначения:

    ~ — домашняя папка пользователя
    . — текущая папка
    .. — родительская папка

РАЗДЕЛ 2. ПРАВА ДОСТУПА И РАБОТА С ФАЙЛАМИ
Система прав:
Каждый файл имеет права для трёх групп:

    u (user) — владелец файла
    g (group) — группа владельца
    o (others) — все остальные

Типы прав:

    r (read) — чтение, значение 4
    w (write) — запись, значение 2
    x (execute) — выполнение, значение 1

Числовой формат прав:

    755 (rwxr-xr-x) — владелец всё, остальные чтение+выполнение. Для скриптов и программ.
    644 (rw-r--r--) — владелец чтение+запись, остальные только чтение. Для обычных файлов.
    600 (rw-------) — только владелец читает и пишет. Для приватных данных и ключей.
    444 (r--r--r--) — только чтение для всех.

Команды работы с правами:
chmod — изменить права
Пример: chmod 755 script.sh
Пример: chmod +x script.sh (добавить право на выполнение)
Пример: chmod 644 file.txt
chown — сменить владельца файла
Пример: chown user:group file.txt
Команды чтения файлов:
cat — вывести всё содержимое файла
Пример: cat config.yaml
less — постраничный просмотр больших файлов
Пример: less huge.log
Навигация: стрелки для прокрутки, q — выход, /слово — поиск
head — показать первые N строк
Пример: head -n 10 log.txt
tail — показать последние N строк
Пример: tail -n 5 log.txt
Пример: tail -f log.txt (мониторинг в реальном времени)
grep — найти строки с текстом
Пример: grep "error" log.txt
Пример: grep -i "error" log.txt (без учёта регистра)
Пример: grep -n "error" log.txt (с номерами строк)
Пример: grep -r "error" /var/log/ (рекурсивно по папкам)
wc — подсчёт строк, слов, символов
Пример: wc -l log.txt (посчитать строки)
РАЗДЕЛ 3. GIT — ОСНОВЫ КОНТРОЛЯ ВЕРСИЙ
Три состояния файла в Git:

    Working directory — файлы на диске (то, что редактируешь)
    Staging area — файлы, подготовленные к коммиту (git add)
    Repository — зафиксированные изменения (git commit)

Основные команды:
git init — создать новый репозиторий в текущей папке
git status — показать статус файлов (изменённые, новые, staged)
git add — добавить файл в staging area
Пример: git add file.txt (конкретный файл)
Пример: git add . (все изменённые файлы)
git commit — зафиксировать изменения
Пример: git commit -m "Initial commit"
git log — показать историю коммитов
Пример: git log --oneline (компактный вид)
git branch — показать текущую ветку
Пример: git branch -M main (переименовать ветку в main)
git remote — работа с удалёнными репозиториями
Пример: git remote add origin https://github.com/user/repo.git
Пример: git remote remove origin (удалить привязку)
git push — отправить коммиты на удалённый сервер
Пример: git push -u origin main (-u запоминает связь веток)
Файл .gitignore:
Файл в корне репозитория, перечисляющий файлы, которые Git должен игнорировать.
Пример содержимого .gitignore:
*.log
*.tmp
*.swp
.env
pycache/
.DS_Store
