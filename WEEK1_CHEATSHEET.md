# 📘 Справочник команд Linux и Git (Неделя 1)

## 1. Навигация и файловая система

### Структура файловой системы
| Путь | Описание |
| :--- | :--- |
| `/` | Корневая директория |
| `/home/` | Домашние папки пользователей |
| `/etc/` | Конфигурационные файлы системы |
| `/var/` | Переменные данные (логи, кэш, БД) |
| `/tmp/` | Временные файлы (очищаются при перезагрузке) |
| `/usr/` | Программы и библиотеки пользователей |
| `/bin/` | Основные системные программы |

### Основные команды навигации
| Команда | Описание | Пример использования |
| :--- | :--- | :--- |
| `pwd` | Показать текущий путь | `pwd` → `/home/student` |
| `ls` | Список файлов в папке | `ls -la` (подробно + скрытые)<br>`ls -R` (рекурсивно) |
| `cd` | Переход в директорию | `cd /etc` (в папку)<br>`cd ..` (на уровень выше)<br>`cd ~` (домой)<br>`cd -` (вернуться назад) |
| `mkdir` | Создать папку | `mkdir test`<br>`mkdir -p a/b/c` (создать цепочку) |
| `touch` | Создать пустой файл | `touch file.txt` |
| `cp` | Копировать | `cp file.txt backup.txt`<br>`cp -r folder/ new_folder/` (папку) |
| `mv` | Переместить / Переименовать | `mv file.txt folder/` (переместить)<br>`mv old.txt new.txt` (переименовать) |
| `rm` | Удалить | `rm file.txt`<br>`rm -r folder/` (папку с содержимым)<br>`rm -f file.txt` (без подтверждения) |

### Типы путей
*   **Абсолютный путь:** Начинается с `/` или `~`. Всегда указывает на одно и то же место.
    *   *Пример:* `/home/student/devops-learning/scripts/test.sh`
*   **Относительный путь:** Не начинается с `/`. Зависит от текущей директории (`pwd`).
    *   *Пример:* Находясь в `devops-learning/`, путь `scripts/test.sh` ведёт к тому же файлу.

### Специальные обозначения
*   `~` — домашняя папка текущего пользователя.
*   `.` — текущая папка.
*   `..` — родительская папка (уровень выше).

## 2. Права доступа и работа с файлами

### Система прав (chmod)
Каждый файл имеет права для трёх групп: **u** (владелец), **g** (группа), **o** (остальные).
Типы прав суммируются в число: **r** (4) + **w** (2) + **x** (1).

| Число | Права | Расшифровка | Когда использовать |
| :--- | :--- | :--- | :--- |
| `755` | `rwxr-xr-x` | Владелец: всё, остальные: чтение+выполнение | Скрипты, программы |
| `644` | `rw-r--r--` | Владелец: чтение+запись, остальные: только чтение | Обычные файлы, конфиги |
| `600` | `rw-------` | Только владелец читает и пишет | Приватные ключи, пароли |
| `444` | `r--r--r--` | Только чтение для всех | Важные документы (защита от изменений) |

### Команды управления правами
*   `chmod 755 script.sh` — установить права численно.
*   `chmod +x script.sh` — добавить право на выполнение (удобно для скриптов).
*   `chown user:group file` — сменить владельца и группу файла.

### Чтение и поиск в файлах
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `cat` | Вывести всё содержимое | `cat config.yaml` |
| `less` | Постраничный просмотр | `less huge.log` (выход: `q`, поиск: `/слово`) |
| `head -n N` | Первые N строк | `head -n 10 log.txt` |
| `tail -n N` | Последние N строк | `tail -n 5 log.txt` |
| `tail -f` | Мониторинг в реальном времени | `tail -f /var/log/syslog` |
| `grep "текст"` | Поиск строк с текстом | `grep "error" log.txt`<br>`grep -i "error"` (без учёта регистра)<br>`grep -r "error" /var/log/` (рекурсивно) |
| `wc -l` | Подсчёт строк | `wc -l log.txt` |

## 3. Git: Основы контроля версий

### Три состояния файла
1.  **Working Directory** — файлы на диске (то, что вы редактируете).
2.  **Staging Area** — файлы, подготовленные к коммиту (`git add`).
3.  **Repository** — зафиксированные изменения (`git commit`).

### Основные команды
| Команда | Описание |
| :--- | :--- |
| `git init` | Инициализировать репозиторий в текущей папке |
| `git status` | Показать статус файлов (изменённые, новые, staged) |
| `git add <file>` | Добавить файл в staging. `git add .` — добавить всё |
| `git commit -m "msg"` | Зафиксировать изменения с сообщением |
| `git log --oneline` | История коммитов (кратко: хеш + сообщение) |
| `git branch` | Показать ветки. `git branch -M main` — переименовать в main |
| `git remote add origin <url>` | Привязать удалённый репозиторий (GitHub) |
| `git push -u origin main` | Отправить код на сервер. `-u` запоминает связь веток |
