# Week 1 Summary

## Изучено:
- Структура файловой системы Linux (/home, /etc, /var, /tmp)
- Команды навигации: pwd, ls, cd, mkdir, touch, cp, mv, rm
- Права доступа: chmod (числовой формат), владелец/группа/others
- Работа с файлами: cat, less, head, tail, grep, wc
- Git: init, add, commit, log, remote, push
- GitHub: создание репозитория, Personal Access Token

## Сложности:
- Путаница с абсолютными/относительными путями (решено через pwd)
- Ветка master vs main (решено через git branch -M main)
- Fine-grained vs Classic token (решено переключением на classic)
